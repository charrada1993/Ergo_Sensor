# 🤖 Ergo Sensor — AI Engine Models Package (v3.0-Production)

This directory contains the serialized machine learning models, preprocesses, and diagnostic plots for the **Ergo Sensor AI Engine v3.0-Production**.

---

## 🗂️ Model Manifest

### 1. Core Exposure & Predictive Models
*   **`lgb_regressor.txt`**: LightGBM regressor predicting continuous 10-day musculoskeletal injury probability `[0.0 – 1.0]`. Optimized with Optuna and trained with `TimeSeriesSplit` cross-validation.
*   **`lgb_classifier.txt`**: LightGBM 18-class condition classifier identifying specific pathological conditions (e.g., Carpal Tunnel, Lumbar Disc Herniation, Cervicalgia). Configured with balanced class weights to combat data skew.
*   **`lgb_severity.txt`**: LightGBM 3-class severity classifier tagging postural risk severity as `low`, `medium`, or `high`.
*   **`isolation_forest.pkl`**: Unsupervised anomaly detection model trained to identify novel or pathologically irregular joint configurations.

### 2. Binary Joint Anomaly Classifiers
Five dedicated binary LightGBM classifiers trained to trigger alerts when specific joints exceed safe ergonomic angle thresholds:
*   **`lgbm_anomaly_neck_hyperflex.txt`** (Threshold: Neck flexion > 44.5°)
*   **`lgbm_anomaly_shoulder_overext.txt`** (Threshold: Shoulder extension/flexion > 96.6°)
*   **`lgbm_anomaly_wrist_strain.txt`** (Threshold: Wrist deviation/flexion > 36.2°)
*   **`lgbm_anomaly_trunk_torsion.txt`** (Threshold: Trunk rotation > 64.0°)
*   **`lgbm_anomaly_elbow_hyperext.txt`** (Threshold: Elbow internal angle > 103.0°)

### 3. Preprocessing & Scalers
*   **`feature_scaler.pkl`**: StandardScaler mapping the 75-feature vector into normalized space for prediction.
*   **`scaler_if.pkl`**: MinMaxScaler used specifically to normalize metrics for the Isolation Forest outlier detector.
*   **`model_metadata.json`**: Central JSON dictionary containing model definitions, feature lists, encoding dictionaries, metrics, and thresholds.
