# Changelog

## [3.0.0-Production] - 2026-06-04

### Added
- **AI Engine v3.0**: Migration to 75-feature vector (from 38).
- **Time-Series Logic**: Added rolling means, variances, and lag features to feature extraction.
- **Optuna Optimization**: Automated hyperparameter tuning for LightGBM models.
- **Explainability**: Integrated SHAP TreeExplainer for real-time risk factor analysis.
- **3D Digital Twin**: Live Three.js visualization of worker kinematics.
- **Bilateral Engines**: RULA and REBA now support independent left/right side scoring.
- **Documentation**: Comprehensive technical encyclopedia and defense guide.
- **French Translation**: All documentation files translated to French.
- **Project Structure**: Regrouped all documentation into a centralized `/docs` folder.

### Changed
- **Performance**: Optimized WebSocket broadcasting to maintain 10Hz frequency under high concurrency.
- **UI/UX**: Refreshed dashboard with premium dark-mode aesthetic and orthopedic diagnostic columns.
- **Backend**: Improved thread-safety in `csv_logger.py` and `data_processor.py`.

### Fixed
- **Temporal Leakage**: Resolved data leakage issues in AI training using `TimeSeriesSplit`.
- **Calibration**: Fixed gimbal lock issues in Euler angle calculations using localized reference offsets.

## [2.1.0] - 2026-04-15
